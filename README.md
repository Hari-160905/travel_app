Travel App

It is a travel Diaries app.This platform helps us to save our trip details like travel destination, date, places visited and storing amount spent for specific expenditure.
It major advantage is we can seek help from AI assisstant which helps in trip planning and providing trip-related details.
In this App we can edit, insert, delete trip related details.
Example: changing the start and end date, destination, expenses of the trip.

Technologies used 

Front end: Html,CSS,React.js

Backend: node.js,express.js,rest APIs
Database: MYSQL
LLM-Intgerated: Google Gemini API.
